MALO-TCG Windows 轻量启动器 · 0.1.3 试用版

使用：解压整个文件夹，双击 MaloTCG.exe。不要只移动 exe，旁边的 DLL 必须保留。
需要：Windows 10/11 x64、.NET Framework 4.8、Microsoft Edge WebView2 Evergreen Runtime。
本程序使用系统网页组件，不打包完整浏览器；首次加载在线界面需要网络。

1. 在主页输入现有用户 ID 和密码登录；首次使用可先点击“立即同步”确认云端记录已读取。
2. 点击顶部“悬浮”或网页的悬浮窗按钮，进入无系统标题栏、置顶的 150×150 微缩窗。
3. 悬浮时无独立顶部栏：点击右上角“⋯”选择展开／微缩或回到主页，Esc 也可返回主页。按住左上角拖动点移动窗口。
4. “⋯”菜单还可切换置顶、面板不透明度、刷新、最小化及关闭。默认整个面板为 90% 不透明，背景连续覆盖到四周与底部。
5. F5 刷新在线页面；关闭再打开即可加载最新在线界面。

数据：浏览器与启动器的本地存储各自独立。使用同一账号，沿用现有自动上传及十分钟检查云端的规则，也可手动立即同步。
悬浮时主页面留在同一个窗口后台，登录会话和同步继续运行。启动器使用 Windows 当前用户加密保存有效登录凭证，不保存密码。关闭重开可恢复，服务器当前会话有效期为 48 小时；到期后需要重新登录，退出登录会清除保存的凭证。
本地数据位于 %LOCALAPPDATA%/MaloTCG/Launcher。重放或更新程序文件不会清除该目录。

窗口背景透明，文字保持正常不透明；不是透过窗口实时磨砂游戏画面。当前不提供鼠标穿透。
独占全屏游戏的覆盖效果尚待实际游戏验证，建议先使用窗口化或无边框窗口模式。
试用版未进行代码签名，也未实现启动器自身的自动更新。界面与记录逻辑从 https://malo-ptcg.cn 加载。
若网站结构或底层窗口能力变化，启动器可能需要更新；不会自动下载执行新程序。

演示：命令行运行 MaloTCG.exe --demo，使用独立演示存储，不登录云端。
