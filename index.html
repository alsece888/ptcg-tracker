0.1.8 更新：优化微缩窗排版：修复四角深色三角，移除重复的透明圆角层；保留布局、配色及透明度。保持 150×150，登录有效期 48 小时。已下载旧版的用户需要重新下载，刷新网页不会更新启动器本身。

解压整个文件夹，再双击 MaloTCG.exe，旁边的 DLL 文件请保留。使用网页版同一账号登录后，点击「立即同步」读取云端记录；后续沿用网页版的同步规则。

需要 .NET Framework 4.8 和 Microsoft Edge WebView2 运行环境。首次加载需要联网；启动器加密保留有效登录，退出登录或凭证到期后需要重新登录。此试用版未签名，真实账号数据互通和实际游戏覆盖仍待试用验证。

🔌 数据中转

浏览器无法直接访问小天冠山 API（跨域限制），必须经过「中转」取数据。 刷新排位数据时会同时并发尝试几个中转，谁先返回可用数据就用谁。 公共中转可能随时失效，可在此检测可用性，或填入你自己部署的中转地址（见 RELAY.md，五分钟可搞定）。
